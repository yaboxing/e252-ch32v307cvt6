操作提示

· 从站无法进入 SAFEOP/OP 时，优先核对 AL 状态码与 SII/对象字典是否一致。

· 0x001E 输入配置无效：常见于 EEPROM 中的 SII 来自其它工程，导致主站按错误映射配置 SM3/FMMU。

· 0x001B 同步管理器看门狗：确认周期通信未暂停，或增大周期时间。

· SDO 读写仅在 PREOP 及以上状态可用。
