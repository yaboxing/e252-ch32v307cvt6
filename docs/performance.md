# 性能测试

本文给出本固件的可复现性能结果：帧周期/帧率、PDI 与中断、SM 看门狗、PDO 原子性、SPI 时钟上限、DC/SYNC。所有数字都附带测量条件；**离开这些条件，数字不具可比性**。能力分级见 [capability.md](capability.md)。

## 1. 测试条件

| 项 | 值 |
|---|---|
| ESC / 板卡 | SYS-E252 / DPORT_ECAT V2.2（QMX102 载板） |
| MCU | CH32V307VCT6，SYSCLK 96 MHz |
| PDI | SPI1（PA5/PA6/PA7），SCK 24 MHz，DMA，CS=PB12 |
| 引脚 | IRQ=PA3、SYNC0=PA4、SYNC1=PB11、RST=PB0 |
| 固件 | SSC 5.11 移植；CSR 32 位忙轮询（上限 4096）；SM2/SM3 单次 6 B 事务 |
| PDO | 6 B / 6 B；SM2 `0x1200`、SM3 `0x1300`；控制字 SM2=`0x64`、SM3=`0x20` |
| 看门狗 | `0x0400=0x09C2`（分频 2498）、`0x0420=0x03E8` → 100 ms |
| 主站（常规） | pysoem 1.1.13 + Windows + 千兆网卡，100 Mbps 链路 |
| 主站（极限） | SOEM 自定义 C 程序，忙等发送 |
| 过程数据 | `5A 00 34 12 78 56`（输出）；输入按实际 IO 变化 |
| 串口 | USART1 115200 8N1，板载 WCH-LinkE |

**通用方法**：每段预热 2 s、测量 12 s；同一会话内连续跑 1/2/4 ms 三个目标；重复 3 次取中位数。帧间隔、WKC、AL 状态逐帧记录；从站侧通过串口 `[IRQ]`、`[IRQM]`、`[WD]`、`[DCS]`、`[SYNCPIN]` 行交叉核对。

指标定义：

- **WKC=3**：输出、输入、状态三处工作计数器都正确。
- **lat_us**：IRQ 中断入口 → 读走 AL Event 的时间。
- **lock_us**：PDI 临界区最长关闭窗口。
- **撕裂率**：固件整帧采样既不是 A 帧也不是 B 帧的比例。

## 2. 帧周期与帧率

### 2.1 pysoem + `sleep`（常规主站）

3 次中位数，最长 12 s/段：

| 段 | 目标周期 | 实际帧率 | 帧间隔 p50/p95/p99 | p99 max | WKC=3 | WKC<0 | AL |
|---|---|---|---|---|---|---|---|
| P1 | 1 ms | 421.4 帧/s | 2.151 / 3.574 / 6.594 ms | 23.4 ms | 99.83% | 0.17% | 全程 `0x08` |
| P2 | 2 ms | 304.1 帧/s | 3.124 / 4.051 / 6.120 ms | 45.8 ms | 99.77% | 0.23% | 全程 `0x08` |
| P3 | 4 ms | 192.1 帧/s | 5.130 / 5.604 / 6.606 ms | 24.2 ms | 99.87% | 0.13% | 全程 `0x08` |

结论：Windows `time.sleep` 粒度约 1 ms 且偏大，实际 p50 为 2.15/3.12/5.13 ms。**这是主站侧限制**，不能用于判断从站上限。丢帧 `WKC<0` 0.13–0.23%，从站侧 `nf/fr/stuck/dmaerr=0`。

| 0.40 ms | 0.773 ms | 1153.9/s | 99.83% | 0.17% | 0x08 | 边界 |

| 连发 | 0.689 ms | 1418.8/s | 99.92% | 0.08% | 0x08 | 主站地板 |

| 目标周期 | `EXT3/s` | `PDI/s` | 比例 | lat_us | lock_us | `nf` | AL / CODE |

| 2.00 ms | 500.0 | 500.0 | 1.00 | 17/17/17 | 147 | 0 | 0x08 / 0x0000 |

| 0.50 ms | 1087.8 | 1087.8 | 1.00 | 17/17/17 | 147 | 0 | 0x08 / 0x0000 |
| 连发 | 1004.5 | 1004.5 | 1.00 | 17/17/17 | 147 | 0 | 0x08 / 0x0000 |

> 该表在开启串口监控的条件下（`[IRQM]`），主站节拍被串口线程拖慢，因此“连发”档只有 1004.5 帧/s；同一固件在无串口监控的纯主站循环下可达 1418.8 帧/s（见上表）。两组数字不能混用。

结论：

- 目标 **≥1 ms** 可用；主站地板约 **0.689–0.770 ms（≈1420 帧/s）**，目标再小实际周期不再下降。
- 从站 `EXT3:PDI` 严格 1:1 到 **≈1.2 kHz**，全程无 `0x001B`、`csrTmo=0`。**从站在 ≤1.42 kHz 范围内余量充足**；真实上限需硬实时主站，未验证。
- 忙等测量会占满 GIL，串口线程易饿死；必须在 `[IRQM]` 行数完整时才判读服务率（测量时 `switchinterval=0.0005`）。

**复现要点**：pysoem 下 `send_processdata()`/`receive_processdata()` 循环，`expected_wkc=3`；1 kHz 段用 `perf_counter` 忙等。每段至少 12 s，记录 `WKC`、`AL` 与串口 `[IRQM]`。

## 4. SM 看门狗

### 4.1 量程与线性（`0x0420`，单位 100 µs，16 位）

| 写入 | 配置 | 到期点 | 判定 |
|---|---|---|---|
| `0x0800` | 204.8 ms | 205.28 ms | 线性 |
| `0x1000` | 409.6 ms | 410.03 ms | 线性 |
| `0x2000` | 819.2 ms | 819.67 ms | 线性 |
| `0x4000` | 1638.4 ms | 1638.48 ms | 线性 |
| `0x8000` | 3276.8 ms | 3277.44 ms | 线性 |
| `0xC000` | 4915.2 ms | 3.5 s 内未到期 | 与外推一致 |
| `0xFFFF` | 6553.5 ms | 3.5 s 内未到期 | 与外推一致 |
| `0x0000` | 禁用 | 停帧 400 ms 不超时，`0x0440=0x0001` | 禁用有效 |

到期点 = 配置值 + FPRD 往返约 0.7 ms。范围 **0–6553.5 ms**，步长 100 µs，全 16 位线性。

### 4.2 窗口与超时行为

| `0x0420` | 配置 | 到期点 |
|---|---|---|
| 1000（默认） | 100 ms | 98.09 ms |
| 500 | 50 ms | 50.13 ms |
| 200 | 20 ms | 20.48 ms |
| 100 | 10 ms | 10.56 ms |
| 50 | 5 ms | 5.37 ms |

超时后：

- `0x0130 = 0x0014`（SAFEOP + Error）
- `0x0134 = 0x001B`（SM Watchdog）
- `0x0440` bit0 首读为 0（已超时），读操作清除；再读为 1
- `0x0442` 过程数据计数 +1
- 主站 WKC 归零、状态退回 SAFEOP

恢复必须按序：`0x0120=0x0014 → 0x0004 → 0x0008`。直接写 OP 或 `recover()` 清不掉错误位。若窗口小于帧周期，ack 后进 OP 会立即再次超时；恢复前先把 `0x0420` 放大到 100 ms。

### 4.3 最小可靠窗口（2 ms 帧周期，每档独立进程 3 s，1500 帧）

| units | 窗口 | AL / CODE | 判定 |
|---|---|---|---|
| 10–50 | 1–5 ms | `0x0014 / 0x001B` | 不可用 |
| 100 | 10 ms | `0x0008 / 0x0000` | **可用** |

结论：本非实时 Windows 主站下，2 ms 周期最小可靠窗口约 **10 ms（≈5× 帧周期）**。≤5 ms 即使有 2 倍余量也会被 6–22 ms 的调度停顿误触发。**该下限由主站抖动决定，不是从站能力边界**；默认 100 ms 余量 ≥100 倍。

## 5. SM 缓冲模式与 PDO 原子性

条件：2 ms 帧周期，A/B 帧逐帧交替；每段 15 s；`5A 00 34 12 78 56` / `A5 00 34 12 78 56`；撕裂率按固件整帧采样统计。

| 段 | SM2 控制字 | 回读 | OP | WKC=3 | A/B/other | 撕裂率 | 判定 |
|---|---|---|---|---|---|---|---|
| 三缓冲（默认） | `0x64` | `0x64` | 是 | 99.89% | 2382/2342/0 | 0.00% | **可用** |
| 邮箱单缓冲 | `0x66` | `0x66` | 是 | 99.92% | 213/207/4304 | 91.11% | **不可用**（读空邮箱） |
| 保留 `01` | `0x65` | `0x65` | 否 | 0% | 0/0/0 | — | 不可用（掉 SAFEOP，随后 `0x001B`） |
| 保留 `11` | `0x67` | `0x67` | 是 | 99.88% | 2382/2342/0 | 0.00% | 规范保留，不可用于产品 |
| 恢复三缓冲 | `0x64` | `0x64` | 是 | 99.76–99.91% | ≈1:1/0 | 0.00% | 恢复成功，无需复位 |

- **RxPDO 必须三缓冲**：7236 个段内采样撕裂率 0.00%，A/B 比 0.497–0.504，逐帧原子且新鲜。
- 邮箱单缓冲对 SM3（TxPDO）可用：40 s / 20,000 帧记录到 19,969 次 6 B 全变，逐帧无漏；按键保持 20 s / 10,000 帧，4 个边沿无重复、两端一致。
- 改 SM 模式约 0.15 s 空档，会话期需把 `0x0420` 放大，否则触发 `0x001B`。

**工程约束**：主站必须在进 OP 前开始周期性发送过程数据，并在 OP 期间持续发送；不要“先进 OP 再发帧”。

## 6. SPI 时钟上限

SYSCLK/SPI 组合扫描，读取 `BYTE_TEST` 与 `ID_REV`：

| SYSCLK / SCK | `BYTE_TEST` / `ID_REV` | lat min/avg/max | `byte_ns` | cmd/poll/data | lock_us | 判定 |
|---|---|---|---|---|---|---|
| 96 / 48 MHz | `0xC3B2A190` / `0x49298080` | — | — | — | — | 不可用 |
| 80 / 40 MHz | 同上 | — | — | — | — | 不可用 |
| 72 / 36 MHz | 同上 | — | — | — | — | 不可用 |
| 64 / 32 MHz | 同上 | — | — | — | — | 不可用 |
| 56 / 28 MHz | `0x87654321` / `0x92520001` | 22/22/23 | 313 ns | 5/5/5 | 613 | 可用，但更慢 |
| 48 / 24 MHz | `0x87654321` / `0x92520001` | 26/26/27 | 365 ns | 6/6/6 | 716 | 可用，最慢 |
| **96 / 24 MHz** | **`0x87654321` / `0x92520001`** | **16/16/16** | **348 ns** | **4/3/4** | **372** | **综合最优** |

失效机理：

- E252 读操作规格上限 30 MHz；失效阈值在 (28, 32] MHz。
- 48 MHz 时 CPHA=0 的采样窗口 T/2 = 10.42 ns < 30 pF 负载的 11 ns，必然采到上一位，表现为整帧右移 1 位。
- CS 建立/保持不是原因（插 5 µs gap 无效）；CPOL/CPHA 四组合均无法同时满足读写；本片 HSRXEN 无效。
- 飞线使有效 `tV` 从规格 11 ns 抬到 **15.6–17.9 ns**，压缩了 24–30 MHz 的余量，但不是 48 MHz 不可用的主因。
- 24 MHz 是稳定点，28 MHz 档虽然通过，但 CPU 主频降到 56 MHz，综合延迟 22 µs，反而更慢。

## 7. DC / SYNC

### 7.1 寄存器配置（主站 FPRD 与固件 PDI 直读一致）

| 寄存器 | 语义 | 无 DC | SYNC0 1 ms | SYNC0+SYNC1 |
|---|---|---|---|---|
| `0x0141` | DC/中断配置 | `0x000E` | `0x000E` | `0x000E` |
| `0x0151` | SYNC0/1 输出使能 | `0x0044` | `0x0044` | `0x0044` |
| `0x0980` | 循环单元控制 | `0x0000` | `0x0003` | `0x0007` |
| `0x0981` | 激活 | `0x00` | `0x03` | `0x07` |
| `0x0982` | 脉冲宽度 | — | `0x2710`（100 µs） | `0x2710` |
| `0x09A0` | SYNC0 周期 | 0 | 1,000,000 ns | 1,000,000 ns |
| `0x09A4` | SYNC0→SYNC1 间隔 | 0 | 0 | 500,000 ns |

本板 EEPROM 默认已使能 DC 单元与两路输出，主站只需写 `0x0981/0x0982/0x09A0/0x09A4`。`0x0984=0`（首脉冲已处理）与 `0x098E/0x098F=0`（应答模式读清）都是正常状态，不是故障。

### 7.2 三模式对比（A/B/C 各 20 s，帧间隔目标 2 ms，实际约 3.05 ms）

| 档 | 相位配置 | 帧率 | WKC=3 | 帧间隔 p50/p95/p99/max | AL |
|---|---|---|---|---|---|
| A 无 DC | `0x0980=0` | 323.3/s | 99.77% | 3.076/3.518/4.045/11.561 ms | 全程 OP |
| B SYNC0 only | `0x0980=3`、`0x09A0=1 ms` | 318.8/s | 99.70% | 3.067/3.567/4.532/10.754 ms | 全程 OP |
| C SYNC0+SYNC1 | `0x0980=7`、`0x09A4=500 µs` | 315.2/s | 99.68% | 3.088/3.593/4.617/13.631 ms | 全程 OP |

从站侧三档的 `lat_us`、`lock_us`、`stuck`、`deas_us`、`EXT3:PDI=1:1`、`WDSTAT=0x0001` 完全一致 → **DC 不改变 PDI 时序**。

### 7.3 引脚电平（2 ms 窗口采样）

| 档 | SYNC0 (PA4) | SYNC1 (PB11) | SYNC1 相位 |
|---|---|---|---|
| A 无 DC | `chg=0`，静止高 | `chg=0`，静止高 | — |
| B SYNC0 only | `chg=4`，脉宽 98–99 µs | 无脉冲 | — |
| C SYNC0+SYNC1 | `chg=4`，脉宽 98–99 µs | `chg=4`，脉宽 97–100 µs | `ph_us=499–502`（配置 500） |

`0x09A4=2 ms` 时，SYNC1 周期被量化为 3 ms（`⌊2/1⌋+1`），下一个 SYNC1 与 SYNC0 差约 1.017 ms。SYNC1 是 SYNC0 的派生信号，**不是独立周期**。

### 7.4 主从时间偏差（受主站限制）

- 绝对偏置约 `8.474×10¹⁷ ns` 恒定，是主站收帧路径的固定延迟，不是同步误差。
- 逐帧 offset 抖动：SYNC0 档 p90p2p 245.5 µs、p99 +103 µs；SYNC0+SYNC1 档 p90p2p 277.5 µs、p99 +153 µs。
- 1 Hz 采样漂移：3.9 ppm / 11.0 ppm；单帧尖峰 −11.34/−7.61 ms 来自 Windows/USB 收帧时间戳。
- **判读**：只能声明“主从展宽上界约 0.2–0.3 ms”，不能把该值归为从站 DC 抖动。SYNC ≤15 ns 与晶振长期漂移需示波器/频率计，未验证。

## 8. 结果解读与边界

1. 1 kHz 稳定 OP 是**主站忙等**条件下的结论；普通 Windows 主站无法达到 1 ms，不应归因于从站。
2. 从站 PDI 的 16–17 µs 与 1:1 服务率，在 ≤1.42 kHz 的可观测范围内余量充足；更高帧率未验证。
3. 看门狗精度是 100 µs 步长 + 0.7 ms 测量误差；最小可用窗口由主站抖动决定。
4. SPI 24 MHz 是飞线条件下的稳定点；28 MHz 可用但不是最优，32 MHz 以上不可用。
5. DC 三种组合均可用；SYNC1 只能做相对 SYNC0 的相位/间隔，不能独立定周期。
6. 所有绝对时间指标都含主站网卡收帧延迟，跨机比较时应使用同机同网卡的 `gap_p95`，而不是绝对 p50。
