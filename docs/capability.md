# 能力清单

本文列出本固件在当前硬件与软件环境下的能力边界。**只有标注“实测确认”的条目才视为已交付能力**；“文档声称”是器件手册给出的指标，“未验证”是尚未取得运行证据的项，“硬件受限”是当前板卡/封装无法支持的项。测量条件与原始数据见 [performance.md](performance.md)。

## 0. 测试环境

| 项 | 值 |
|---|---|
| ESC | SYS-E252（DPORT_ECAT V2.2，QMX102 载板） |
| MCU | CH32V307VCT6（96 MHz，3.3 V IO） |
| 固件 | SSC 5.11 移植；PDI 为 SPI1 + DMA，SCK 24 MHz |
| 过程数据 | RxPDO 6 B / TxPDO 6 B |
| 主站（功能测试） | pysoem 1.1.13 + Windows + 千兆网卡 |
| 主站（1 kHz 极限测试） | SOEM 自定义 C 程序，忙等发送 |

证据等级：

- **实测确认**：在第 0 节环境下有运行结果（状态、计数、时间戳或波形）。
- **文档声称**：来自 E252/CH32V307 手册或 SSC 文档，本板未逐项覆盖。
- **未验证**：没有运行证据，不能对外宣称可用。
- **硬件受限**：受当前板卡、封装或接线限制，不能通过改固件实现。

|---|---|---|---|---|
| 19 | 过程数据长度 | 6 B / 6 B | 实测确认 | 与 ESI、SII、OD 一致 |

## 6. 主站工具链限制（非从站能力）

以下现象由主站/操作系统引起，不应记为从站缺陷：

- pysoem 读取 `0x1C32/0x1C33` 在 Windows 上会崩溃（`0xC0000005`），通过 ESC 寄存器 FPRD 读取，或换主站。
- Windows 定时器粒度导致 `sleep` 周期无法低于约 2.37 ms；1 kHz 必须忙等或实时主站。
- 不同主站对 SM2/SM3 单/三缓冲、看门狗窗口的默认值不同，联调时以本仓库 ESI 与本表为准。

## 7. 未验证项与核对方法

| 项目 | 建议核对方法 |
|---|---|
| 12/24/32/68 B PDO | 同步改 OD、SII、ESI、IOmap；用 1 kHz 连续跑 10 min，统计撕裂与 WKC |
| SYNC 抖动 | 示波器测 SYNC0/SYNC1，10 s 以上，统计峰峰值与标准差 |
| 2/4 ms DC 周期 | 修改 `0x09A0/0x09A1`，重复第 5 节用例 |
| 晶振漂移 | 连续 1–4 h 记录系统时间差与温度 |
| 光纤 / 可变 VDDIO | 需改板或换模块，当前硬件不可达 |
| ETG 一致性 | 使用 ETG 官方测试工具，当前未做 |
