# 竞品对比：E252 vs LAN9252 / ET1100

本文只写**有本仓库资料依据**的差异。竞品板卡尚未上电对比，竞品芯片的完整手册也未全部归档，因此不比较功耗、内部资源数量、时序极限等缺少依据的指标。资料互相矛盾处明确标注“待厂商确认”。

## 0. 证据等级

| 标记 | 含义 |
|---|---|
| **确定** | 有原理图、源码或手册原文直接支撑 |
| **文档声称** | 来自 E252/竞品手册或厂商适配说明，未做独立复测 |
| **未验证** | 无证据，不能对外宣称 |
| **待厂商确认** | 两份资料给出不同结论，需原厂书面答复 |

对比基准：E252 DPORT_ECAT V2.2 + CH32V307VCT6，6 B / 6 B IO 从站，SPI PDI 24 MHz。竞品参考工程为 LAN9252 + DSP28335 与 ET1100 + STM32F417 的交付包。

---

## 1. E252 的技术事实

| 维度 | 结论 | 等级 |
|---|---|---|
| 角色 | EtherCAT 从站控制器，集成 2 路 PHY；本板为 2 个 RJ45 | 确定（本板） |
| ESC 资源 | 8 FMMU、8 SM、8 KB DPRAM、64 位 DC | 文档声称（[数据手册](thm/E252_EtherCAT_Controller_Manual.pdf)） |
| 主机接口 | SPI（READ `0x03`、FASTREAD `0x0B`、WRITE `0x02`），16 位地址 | 确定（本工程实现 `0x03/0x02`；`0x0B` 为手册能力） |
| 本工程 SPI 时钟 | 24 MHz 稳定；28 MHz 起读错 | 确定 |
| 过程数据 | 6 B / 6 B，SM2 `0x1200`、SM3 `0x1300`，三缓冲 | 确定 |
| DC | SYNC0 1 ms、SYNC1 相对偏移 | 确定 |
| 封装 | QFN64 9×9 / TQFP-EP 64 10×10 | 文档声称 |

## 2. 与 LAN9252 的差异

### 2.1 引脚兼容性

| 项 | 结论 | 等级 |
|---|---|---|
| 封装与引脚定义 | 厂商口径为 **pin-to-pin 兼容**（同为 64 引脚，数据手册引脚表 51–64 与 [LAN9252 手册](thm/LAN9252_Technical_Manual_CN.pdf) 一致） | 文档声称；**未验证** |
| 直接替换是否需要重画 PCB | 按上述口径不需要 | 文档声称 |
| 板级外围是否零改动 | **不是**，有 3 项 BOM/上电配置差异（见 2.2） | 确定 |

结论：可以按“引脚兼容 + 3 项板级适配”评估，但不要表述为“零改动直接换料”。是否真能直贴需实板焊接/回板测试；当前没有实板数据。

### 2.2 三项板级差异

| # | 差异 | 本板情况 | 等级 |
|---|---|---|---|
| 1 | IO 电压 | 本板 `VDDIO` 由 AMS1117-3.3 固定为 3.3 V，SPI/SYNC/IRQ 均在 3.3 V 下工作 | 确定（原理图） |
| 2 | 网络变压器中心抽头 | 本板中心抽头**不上拉**，上拉电阻位 `NC`，由电容到地；100 Mbps 链路与 OP 正常 | 确定（原理图） |
| 3 | 光纤模式 | 本板 `FXSDA/B`、`FXLOSEN` 均下拉，配置为铜缆；仅支持 SD 模式光纤属厂商说明 | 铜缆配置固定；光纤能力**未验证** |

**VDDIO 资料矛盾（重点）**：

- E252 [数据手册](thm/E252_EtherCAT_Controller_Manual.pdf) 电气表（表 4-13）写 `VDDIO = +1.8 V ~ +3.3 V 可变 I/O 电源`；
- 《E252 与 LAN9252 硬件适配说明 V1.2》写“E252 不支持可变电压，仅支持 3.3 V IO”；
- 本板实际固定 3.3 V，只能说明 **3.3 V 可用**，不能据此判断 1.8/2.5 V 可用或不可用。

→ **芯片是否支持可变 VDDIO：待厂商确认。** 在确认前，工程上按“本板只用 3.3 V IO”执行。若原 LAN9252 板使用 1.8/2.5 V IO，替换前必须改电平或改拓扑，不能直接套用。

### 2.3 PDI 协议

| 项 | LAN9252 方案 | E252 | 结论 |
|---|---|---|---|
| 事务模型 | 命令 + 两字节地址 + CSR/PRAM 间接窗口 | 同族 | **可平移** |
| 读/写命令 | `0x03` / `0x0B` / `0x02` | 同 | 确定 |
| 寄存器窗口 | `0x0300` CSR 数据、`0x0304` CSR 命令、`0x0308/0x030C` PRAM 读、`0x0310/0x0314` PRAM 写；FIFO `0x0004/0x0020` | 同 | 确定 |
| 复用方式 | `lan9252_pdi_access` 的 CSR/PRAM 事务模型可直接沿用 | — | 可行 |

因此 LAN9252 → E252 的端口层属于“参数/地址级适配”，不是重写。注意 E252 的地址与尺寸约束：`size=1` 任意对齐可用，`size=2` 奇地址、`size=4` 非 4 字节对齐会卡死，端口层必须拦截。

### 2.4 ESI / SII / 对象字典

| 项 | LAN9252 交付包 | E252 本工程 | 结论 |
|---|---|---|---|
| 身份 | 交付包使用 E252 身份 | Man `0xE0000002`、ID `0x26483052`、Rev `0x00010211` | 一致 |
| SM2/SM3 | 交付包使用 E252 地址 | `0x1200` / `0x1300` | 一致 |
| PDO 业务 | 6 B / 6 B IO | 同 | 可沿用结构 |
| ESI/SII | 必须重生成 | 本仓库已提供 | 确定 |

注意：现有 LAN9252 交付包的 ESI 使用 E252 身份，**不能把它当作 LAN9252 原始 ESI**来对比。替换时必须重新生成身份、SM、FMMU 与 PDO 分配，只改 PDO 不改 SM 是典型故障源。

### 2.5 不能声称的对比

- 没有 LAN9252 与 E252 同板、同主站、同周期的 A/B 性能数据；
- 没有两者功耗、FMMU/SM 数量、最大 PDI 频率、DC 精度的对比数据；
- LAN9252 在 1.8/2.5 V IO 下的行为未验证。

## 3. 与 ET1100 的差异

| 项 | ET1100 参考方案 | E252 本工程 | 结论 / 等级 |
|---|---|---|---|
| 封装/引脚 | 与 E252 不同（参考工程为独立封装） | QFN64/TQFP-EP 64 | **不兼容，需改板**（文档/参考工程级） |
| PDI 命令编码 | 地址左移 3 位拼读写位（`(Address << 3) \| ESC_RD/WR`） | 独立命令字节 + 两字节地址 + 间接窗口 | **源码级不兼容**；ET1100 代码不能在 E252 上直接运行 |
| 过程数据访问 | 直接地址空间 | CSR/PRAM 间接窗口 | 不同 |
| ESI 身份 | Vendor `0x00000009`、Product `0x26483059`、Rev `0x00020111` | Vendor `0xE0000002`、Product `0x26483052`、Rev `0x00010211` | 确定 |
| SM 布局 | SM2 `0x1100`、SM3 `0x1400` | SM2 `0x1200`、SM3 `0x1300` | 确定 |
| SSC 应用层 | 对象字典、PDO 分配、CiA402 逻辑 | 可复用 | 结构相同 |
| PDI 端口层 | `el9800hw.c` 直址读写 | 必须重写 | 确定 |

结论：ET1100 → E252 属于“改板 + PDI 端口层重写 + 全状态机回归”，不能按引脚兼容方案评估。

| 维度 | LAN9252 → E252 | ET1100 → E252 |
|---|---|---|
| 封装/引脚 | 厂商口径 pin-to-pin（未验证） | 不兼容，需改板 |
| 3.3 V IO | 可用（本板） | 需按原设计核对 |
| 1.8/2.5 V IO | **待厂商确认** | 未验证 |
| 变压器中心抽头 | 必须不上拉 | 按原设计核对 |
| 光纤 | 铜缆可用；SD 光纤未验证 | 未验证 |
| PDI 协议 | 同族，可平移 | 直址编码，必须重写（源码级） |
| ESI/SII | 必须重生成 | 必须重生成 |
| 应用/OD/PDO | 可复用，需重映射 | 可复用，需重映射 |

| 综合代价 | 低（板级 BOM + 描述文件） | 中高（改板 + 端口层重写） |

## 5. 替代实施路径

### 5.1 LAN9252 → E252

1. **硬件**：确认原板 IO 全为 3.3 V；变压器中心抽头上拉电阻不焊；光纤若使用则确认 SD 模式；核对 25 MHz 晶振与负载电容。
2. **PDI**：沿用 LAN9252 风格的 CSR/PRAM 事务；SPI 取 24 MHz，上电用 `BYTE_TEST/ID_REV` 自检；端口层拦截非法尺寸/对齐。
3. **固件**：SSC 端口层改地址/尺寸映射；保持 6 B/6 B；输入 6 B 整体读，避免跨周期撕裂。
4. **描述文件**：重生成 ESI/SII（身份、SM2 `0x1200`、SM3 `0x1300`、PDO/FMMU）；写 EEPROM 前备份，校验 checksum 与 `0x1018` 一致。
5. **验收**：扫描 → PREOP/SDO → SAFEOP → OP → 1 kHz 长稳 → 断流看门狗 → DC 相位/漂移 → 多次重启身份一致。

### 5.2 ET1100 → E252

1. 硬件按 E252 封装重新设计，不能直贴。
2. PDI 端口层整体重写：命令编码为“命令 + 两字节地址”，过程数据通过 CSR/PRAM 间接窗口访问，不能沿用 `(Address << 3) | ESC_RD/WR` 直址编码。
3. 应用层、对象字典、PDO 映射、CiA402 逻辑可保留，但因 SM/FMMU 地址变化，必须重跑全状态机。
4. 不复用 ET1100 的 ESI/SII。

## 7. 结论

1. **LAN9252 → E252**：按厂商口径为 pin-to-pin，适合“板级 BOM/上电配置 + ESI/SII 重生成”的低成本替代；PDI 事务模型同族，端口层可直接适配。但“零改动直贴”未验证，VDDIO 能力存在资料矛盾，需厂商确认。
2. **ET1100 → E252**：封装/引脚不兼容，PDI 协议不同，必须改板并重写端口层；应用层可复用。
3. 对外建议表述：

> E252 与 LAN9252 为 pin-to-pin 兼容，可直接贴装，但需按硬件适配说明调整变压器抽头、光纤模式并重生成 ESI/SII；IO 电压按本板 3.3 V 使用，芯片是否支持 1.8/2.5 V 可变 IO 待原厂确认。E252 与 ET1100 不兼容，需改板并重写 PDI 端口层。

4. 上述性能结论仅针对 E252 + CH32V307 的测试条件，见 [performance.md](performance.md)。
